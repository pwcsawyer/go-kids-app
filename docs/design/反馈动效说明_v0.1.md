# 反馈动效说明 v0.1（Reanimated 3 参数）

> 以 PRD 5.4 / F02 为准：任何操作 200ms 内必须有视觉或声音反馈，目标 100ms（录屏帧计时验收）；落子 = 点按预览 + 再点确认，不自动落子；从棋罐拖子只在新手引导关（P1）；动画 ≥55fps；不得出现 >3Hz 闪烁。棋盘用 react-native-svg，动画用 Reanimated。
> 时长单位 ms。缓动用 `Easing` 名称或 `withSpring` 参数。音效 ID 见 `assets/manifest.json`。

## 实现要点
- 所有动画跑在 UI 线程（worklet），声音用预加载的 `expo-av`/`expo-audio` Sound 对象，**不要在点击时才 load**。
- 音效优先级：同一时刻最多 3 个音效；语音播放时音效 ducking 到 50%。
- “减少动态效果”（iOS Reduce Motion）开启时：位移/弹簧改为 150ms 淡入淡出，保留声音。
- 表情切换用同尺寸 SVG 交叉淡入 60ms，避免闪。
