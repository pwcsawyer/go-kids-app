# 设计决议：对局页（回复 PR #2）2026-11-01（v0.1.1：已与 PRD v1.0 对齐）

> 冲突时以 PRD 为准。平台：仅 iPad 横屏。规则：中国规则数子。

## 1. 落子方式
- 按 PRD“拖拽+点按双模式”，所有关卡和对局都开放（原“拖子只放在引导关”作废）。
- 点按：按下 ≤200ms 内出现按压光圈+“嘟”音效（目标 100ms），抬起即落子，不加 300ms 等待。
- 拖拽：从棋罐拖子，吸附最近交叉点并显示半透明预览子，停留 300ms 预览变实并轻震，松手落子；拖出棋盘弹回，无负面反馈。
- “点两下确认”改为家长设置里的可选项，默认关闭。
- 详细状态与参数：docs/design/交互说明_救猫咪_找朋友_v0.1.md、docs/design/反馈动效说明_v0.1.md。

## 2. 热区与棋盘尺寸
- 热区：以交叉点为中心，边长 max(格距, 48pt)，重叠时取最近交叉点，并吸附（PRD F02 ≥48pt；原 56pt 作废）。
- 只做 iPad 横屏：棋盘边长 = 屏幕短边×0.86，5/7/9 路都开放（iPad mini 9 路格距约 72pt）。手机不在 v1 范围。

## 3. 提子与棋子形象
- 棋子：黑白棋子加眼睛表情（普通/眨眼/开心/紧张），不换动物皮肤。
- 提子：变成小鸟飞走，素材已在 assets/fx/capture_bird_wing_up|down.svg。

## 4. 对局页按钮（一屏只做一件事）
- 保留：倒回去/悔棋（大按钮，不限次数）、提示（灯泡，连续没做对时自动发亮）、重播语音（喇叭，PRD F08）。
- 去掉“看气”按钮：教学关默认显示气的小星星，自由对局不显示。
- “换路数”“重开”放进关卡选择页；“再玩一次”放在结算页。
- 虚手：PRD 要求双方连续 pass 终局（F01），9 路完整对局（D24 起）需要。放在棋罐旁的小“我下完了”按钮（≥64pt），只在完整对局页出现；吃子游戏关卡不显示。终局用中国规则自动数子。
