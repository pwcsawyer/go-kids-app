# 设计决议：对局页（回复 PR #2）2026-11-01（v0.1.2：以 PRD 5.4 / F02 为准）

> 冲突时以 PRD 5.4「已定决策汇总」和 F02 为准。首发设备 iPad。规则：中国规则数子。

## 1. 落子方式
- 对局主方式：**点按预览 + 再点确认**。第一次点：100ms 内出现半透明预览子（`stone_*_preview`）并响“嘟”声（`sfx_preview`）。再点同一点：落子。点别处：预览移过去。不自动落子，没有“预览 300ms 后自动落下”。
- 从棋罐拖子：只在新手引导关使用（P1），拖动时吸附到最近交叉点。
- 反馈时长：任何操作 200ms 内必须有视觉或声音反馈，目标 100ms。
- 详细状态与参数：docs/design/交互说明_救猫咪_找朋友_v0.1.md、docs/design/反馈动效说明_v0.1.md。

## 2. 热区与棋盘尺寸
- 可点格子 ≥56pt（以交叉点为中心，边长 max(格距, 56pt)，重叠时取最近交叉点），并吸附到最近交叉点。
- 首发 iPad：棋盘边长 = 屏幕短边×0.86，5/7/9 路都开放（iPad mini 9 路格距约 72pt）。手机只开 5/7 路；9 路仅在手机横屏且一格 ≥44pt 时开放。

## 3. 提子与棋子形象
- 棋子：黑白棋子加眨眼表情（普通/眨眼/开心/紧张），不换动物皮肤。
- 提子：变成小鸟飞走，素材已在 assets/fx/capture_bird_wing_up|down.svg（素材接入前可先用泡泡顶上）。

## 4. 对局页按钮（一屏只做一件事）
- 保留：悔棋（大按钮，不限次数）、提示灯（连续没做对时自动发亮）。
- 不要“看气”按钮：教学关自动显示气的小星星，自由对局不显示。
- 没有虚手。
- “换路数”“重开”放进关卡选择页；“再玩一次”放在结算页。
- 棋盘渲染用 react-native-svg，动画用 Reanimated。
