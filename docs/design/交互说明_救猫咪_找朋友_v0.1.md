# 交互说明：救猫咪 / 找朋友 v0.1（工程可直接实现）

> 依据 PRD v1.0（以 PRD 为准）。平台：**仅 iPad 横屏**。规则：中国规则（数子），引擎见 `docs/engine-api.md`。
> 全局数值：点击反馈 ≤200ms（目标 ≤100ms）；拖拽预览 300ms；交叉点热区 ≥48pt；按钮 ≥64pt。素材 ID 见 `assets/manifest.json`。

## 0. 通用落子交互（两款游戏共用，对应 F02）

PRD 要求“拖拽 + 点按双模式”，两种都在所有关卡开放。

### 0.1 点按落子
| 步骤 | 触发 | 表现 | 时长 |
|---|---|---|---|
| 1 | 手指按下（touchstart）落在某交叉点热区内 | 该点出现 `fx.hint_ring` 浅色按压光圈；`sfx_preview` | ≤100ms 内出现 |
| 2 | 手指抬起（同一交叉点） | 直接落子：`stone_*_normal` 按“落子”动效落下 + `sfx_place` | 动效 180ms |
| 3 | 抬起时已滑到别的交叉点 | 按拖拽规则处理（见 0.2） | — |

- 点按 **不做二次确认**（PRD 未要求）。家长设置可开启“点两下确认”（第一次点 = 显示 `stone_*_preview` 半透明预览子，再点同一点 = 落子；点别处 = 预览移过去；5s 无操作预览淡出）。默认关闭。
- 防抖：同一手指 200ms 内的重复点击只响应第一次。多指同时触摸：只认第一根手指，其余忽略。

### 0.2 拖拽落子
| 步骤 | 触发 | 表现 |
|---|---|---|
| 1 | 从棋罐（屏幕右侧，≥96pt）按下并移动 >8pt | 棋子跟手放大到 1.15×，位于手指上方 40pt（避免手指遮挡） |
| 2 | 拖动中棋子中心进入某交叉点吸附半径（0.5 格，且 ≥24pt） | 在该点显示 `stone_*_preview`（opacity 0.45），**持续停留 300ms 后**预览变实（opacity 0.45→0.7）并轻震（Haptics.light） |
| 3 | 松手且有吸附点 | 落子（同 0.1 步骤 2） |
| 4 | 松手无吸附点 / 拖出棋盘 | 棋子 250ms 弹回棋罐（spring），**无负面音效、无语音** |
| 5 | 拖拽中途手指离开屏幕边缘/被系统手势打断 | 视为第 4 种，弹回 |

### 0.3 热区
- 每个交叉点热区 = 以交叉点为中心、边长 max(格距, 48pt) 的正方形；相邻热区重叠时取距离最近的交叉点。
- iPad 横屏棋盘边长 = 屏幕短边 × 0.86。iPad mini（744pt 短边）9 路格距 ≈ 72pt，满足 ≥48pt；5/7 路更大。
- 棋盘外侧再扩 0.5 格作为边线点热区。

### 0.4 不可落点（已有子 / 禁入点 / 劫）
- 预览子出现后 150ms 轻摇（±6pt，3 次）并淡出；`sfx_tap_invalid`（很轻）；语音 `vo_common_cant_place` **每关最多播 1 次**，之后只做视觉。
- 不计入“错误次数”（不是答错，只是放不下）。

### 0.5 错误处理（F07，两款游戏共用）
- 答错（合法落子但不是正确着点）：棋子正常落下 → 400ms 后轻摇并淡出撤回 → `sfx_try_again` + `vo_common_try_again`。
- 同一题第 2 次错：额外播放 `vo_common_hint`，正确点出现 `fx.hint_ring` 呼吸光圈（1.2s 周期，持续到下一次落子）。
- 同一题第 3 次错：`vo_common_demo`，自动演示：手指图标从棋罐拖到正确点并落子（1.5s），然后重置该题再让孩子做一次；演示后的通过照样给星。
- 永远不出现“错/失败/扣分/倒计时”。

### 0.6 撤销与退出
- “倒回去”按钮：左下，96pt，不限次数，撤回孩子最后一步（若 AI 已应，则撤两步）。
- 返回：左上，长按 1.5s 触发（进度环），自动保存当前题。
- 一屏只有：棋盘、棋罐、倒回去、重播语音（喇叭）、进度星。

## 1. 救猫咪（提子，PRD D8–D10，M2 共 16 关）

**故事**：坏狐狸（白子）把小猫关进笼子，堵住狐狸最后一口气 → 狐狸被提掉（变小鸟飞走）→ 小猫跳出来。孩子执黑。

### 1.1 关卡数据（关卡 JSON 字段，供 E5/E7）
`type: "capture"`，`size: 5|7|9`，`setup`，`toPlay: "B"`，`answers: [[x,y],...]`（任意一个即对），`maxMoves`（1 = 一步提子题；>1 = 需多步，AI 按 `aiReplies` 或入门 AI 应对），`showLiberties: true|false`，`voiceIds`。

### 1.2 状态机
```
INTRO ──语音结束/点任意处跳过──▶ SHOW_LIBERTIES ──1.2s──▶ WAIT_INPUT
WAIT_INPUT ──落子──▶ RESOLVE
RESOLVE ──提子成功(含目标狐狸)──▶ CAPTURED ──▶ SUCCESS
RESOLVE ──合法但未提──▶ (maxMoves>1 ? AI_REPLY → WAIT_INPUT : WRONG)
RESOLVE ──非法──▶ INVALID → WAIT_INPUT
WRONG ──错误次数 1/2/3──▶ 见 0.5 → WAIT_INPUT / DEMO
SUCCESS ──1.2s──▶ NEXT_LEVEL（每 8 关结束进入奖励 REWARD）
```

### 1.3 各状态表现
| 状态 | 视觉 | 声音 | 时长 |
|---|---|---|---|
| INTRO | 棋盘淡入 300ms，狐狸子 `stone_white_normal`，被围的小猫在格子旁（角色素材待 D2） | `vo_cat_intro` | 语音时长 |
| SHOW_LIBERTIES | 目标狐狸块每口气出现 `liberty_star`（逐个 120ms 间隔弹出，带数数）；只剩 1 气时用 `liberty_star_last`，狐狸换 `stone_white_nervous` 并抖动 | 每颗星一个极轻 `sfx_preview` | 120ms×气数 |
| WAIT_INPUT | 无提示；8s 无操作 → 星星依次闪一遍 + `vo_cat_count_question`；再 8s → 进入提示态（同第 2 次错） | — | — |
| RESOLVE | 落子动效；被落子贴住的狐狸气星减少（星星缩小消失 150ms） | `sfx_place` | 180ms |
| CAPTURED | 被提子先变 `stone_white_nervous` 80ms → 替换为小鸟（`capture_bird_wing_up/down` 交替 8fps）向右上飞出屏幕 700ms；黑子换 `stone_black_happy` | `sfx_capture_bird` + `vo_cat_captured` | 800ms |
| SUCCESS | 绿色光圈 + 小星星飞向右上进度星 | `sfx_correct` + 随机 `vo_common_correct_1/2` | 600ms |

### 1.4 边界情况
- **提错了块**：提掉了别的白子但不是目标狐狸 → 照样播放提子动效（提子本身是对的），然后语音提示“还有一只狐狸哦”，不计错。
- **自己被打吃/被提**（多步题，AI 反提）：黑子变小鸟飞走同样温和，语音“小猫的朋友飞走啦，我们再来！”，该题重置，计 1 次错。
- **提子例外**：落在无气点但能提子 → 合法，按 CAPTURED 处理（引擎 `play` 返回 captures>0）。
- **劫**：M2 关卡不出现劫；若引擎报 `ko`，按 INVALID 处理。
- **多块同时提**：所有被提子同时变小鸟，错开 60ms 起飞，最多同时 8 只（其余直接淡出）。
- **动画进行中再点**：CAPTURED/SUCCESS 期间输入锁定；INTRO 期间点击 = 跳过语音。
- **静音**：所有声音都有视觉对应（星星、光圈、表情），静音可完成。

## 2. 找朋友（连接，PRD D12–D13，M2 ≥12 关）

**故事**：小企鹅（黑子）走散了，在它们之间放子让大家“手拉手”（上下左右相邻才算连上，斜线够不着）。D13 增加：限步数连通 + 切断狐狸（白子）的手。

### 2.1 关卡数据
`type: "connect"`，`groups: [[坐标...],...]`（需要连成一块的黑子），`maxMoves`，`aiCut: bool`（AI 是否尝试切断），`answersAny`（可选，校验脚本用：最少步连通的全部解），`mode: "connect"|"cut"`。

### 2.2 状态机
```
INTRO → WAIT_INPUT → RESOLVE
RESOLVE ──新连接产生──▶ LINKED ──全部同块?──▶ ALL_TOGETHER → SUCCESS
                               └否──▶ (aiCut ? AI_REPLY : WAIT_INPUT)
RESOLVE ──仅斜向相邻──▶ DIAGONAL_HINT → WAIT_INPUT（不计错）
RESOLVE ──步数用完未连通──▶ WRONG（重置该题）
```
判定：用引擎的连通块（同色正交相邻）计算；“连通”= `groups` 内所有子属于同一块。

### 2.3 表现
| 状态 | 视觉 | 声音 | 时长 |
|---|---|---|---|
| INTRO | 走散企鹅轻轻挥手（stone `blink` 每 2–4s 随机眨眼） | `vo_friend_intro` | 语音 |
| LINKED | 新连上的相邻子之间画 `hand_link`，从中点向两端伸展 250ms；相关棋子换 `happy` 600ms；合并后的气星重算（合并动画 200ms） | `sfx_connect` + `vo_friend_linked`（每关首次） | 600ms |
| DIAGONAL_HINT | 斜向两子之间画虚线手臂伸出又缩回（“够不着”） | `vo_friend_diagonal` | 700ms |
| AI_REPLY（cut 模式） | AI 落子前 400ms 等待，让孩子看清 | `sfx_place` | — |
| ALL_TOGETHER | 整条链依次 `happy` 跳起（每子错开 50ms，上跳 12pt） | `vo_friend_all` | 1s |
| SUCCESS | 同救猫咪 | `sfx_correct` | 600ms |

### 2.4 边界情况
- 孩子落在不相关位置：合法、不算错（除非 maxMoves 用完）；步数剩 1 时右上脚印图标轻闪。
- 被 AI 切断：被切断处出现小剪刀动效（D6 待出），语音 `vo_friend_cut`；不计错，只有步数用完才算一次错。
- 连接时顺带提了白子：先播 CAPTURED（小鸟），再播 LINKED。
- 孩子的子被打吃：棋子 `nervous`；被提时同救猫咪边界处理。
- 已连通后多余落子：SUCCESS 后输入锁定，不会发生。
