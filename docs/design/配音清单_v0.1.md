# 配音清单 v0.1（M1/M2）

> `assets/voice/` 里是 **TTS 占位配音**（edge-tts，zh-CN-XiaoyiNeural，语速 -10%），正式版按 D7 用真人亲切女声/童声重录，文件名保持不变即可替换。正式命名表 `voice_Dxx_nn` 由 P2 课程脚本生成，本清单为通用/游戏台词。
> 录音规范：48kHz/16bit 录制，交付 mp3 或 m4a 单声道，响度 -18 LUFS，句首尾留白 ≤150ms，语气温和，不用“错/不对/失败”。
