# 五岁小朋友围棋学习APP · 儿童UX设计规范 v0.1（初稿）

> 产品目标：一个月（约20个学习日，每天10–15分钟）让零基础五岁儿童掌握围棋基本规则：气、提子、连接、做眼、活棋，并能在9路棋盘上完整下一盘。
> 适用对象：设计、开发、内容、配音团队。状态：初稿，待评审。

---

## 1. 五岁儿童认知与操作特点及设计原则

### 1.1 特点
| 维度 | 特点 | 设计含义 |
|---|---|---|
| 识字 | 基本不识字，仅认识少量汉字/数字1–10 | 界面以图标+语音为主，文字仅供家长 |
| 注意力 | 持续专注约10–15分钟 | 单关卡≤2分钟，单次学习≤15分钟 |
| 抽象思维 | 弱，依赖具象形象和故事 | 把“气”具象为猫咪的“出口/呼吸”，“眼”为房子的“窗户/门” |
| 精细动作 | 手指控制不精准，易误触、拖拽易中断 | 大触控目标、吸附落点、落子二次确认可选 |
| 情绪 | 挫败感强，喜欢即时表扬与重复 | 无失败惩罚、高频正反馈、可重复玩 |
| 记忆 | 短时记忆有限，靠重复巩固 | 每个概念多关卡小步递进，间隔复习 |
| 数数 | 能数到10左右 | 气数≤4，用可视化点数（小星星）呈现 |

### 1.2 设计原则
1. **一屏一事**：每屏只有一个任务、一个主要操作。
2. **听得懂就能玩**：任何操作均有语音引导，零文字可完成全部流程。
3. **故事包装规则**：每个规则对应一个角色故事。
4. **永不失败**：只有“再试试”，没有“错误/失败/扣分”。
5. **即时反馈**：操作后≤100ms给出视觉/音效反馈。
6. **小步递进**：每关只新增一个变量（棋子数、棋盘大小、对手行为三选一）。
7. **防误触**：系统按钮（退出、家长区）放角落并需长按/家长验证。
8. **适度刺激**：动画温和，避免闪烁、过度奖励导致成瘾。

## 2. 视觉规范

### 2.1 色板
| 用途 | 名称 | 色值 | 说明 |
|---|---|---|---|
| 主色 | 暖阳橙 | `#FF9F43` | 主按钮、强调 |
| 辅色 | 青草绿 | `#4CD137` | 正确、成功 |
| 辅色 | 天空蓝 | `#54A0FF` | 信息、提示 |
| 提醒色 | 柔粉红 | `#FF7A90` | 温和提醒（替代红色“错误”） |
| 棋盘底 | 原木黄 | `#F3D9A4` | 棋盘面 |
| 棋盘线 | 木纹棕 | `#8B5E34` | 线宽3–4pt |
| 黑子 | 墨黑 | `#2D3436` | 带高光 `#636E72` |
| 白子 | 奶白 | `#FAFAFA` | 描边 `#B2BEC3` |
| 背景 | 米白 | `#FFF8EC` | 主背景 |
| 气/提示点 | 星光黄 | `#FECA57` | 气位标记 |
| 文字（家长） | 深灰 | `#2F3542` | 对比度≥4.5:1 |

规则：不使用纯红 `#FF0000` 表示错误；饱和度适中；黑白子必须带形状/表情辅助区分（色弱友好）。

### 2.2 字号（以 pt 计，iPad基准）
| 层级 | 字号 | 用途 |
|---|---|---|
| 大标题 | 40pt 圆体加粗 | 关卡名（配图标） |
| 数字 | 48pt | 计数、星星数 |
| 按钮标签 | 28pt | 如出现文字，需配图标 |
| 家长区正文 | 18pt | 家长阅读 |
| 最小 | 16pt | 仅家长区说明 |
字体：圆润无衬线（如 思源柔黑 / 站酷快乐体，仅标题）。

### 2.3 触控目标
- 儿童区所有可点元素 **≥64×64pt**，主按钮 **≥96×96pt**。
- 可点元素间距 ≥16pt。
- 棋盘交叉点有效热区 ≥56pt（9路及以下保证；13路仅在家长“进阶”中开放）。
- 落子采用**就近吸附**：手指落在交叉点半径0.5格内即吸附。
- 系统按钮（返回、家长区）放左上/右上角，长按1.5秒触发。

### 2.4 棋盘与棋子
- 起步棋盘：**5路 → 7路 → 9路**（第1周5路，第2–3周7路，第4周9路）。
- 棋盘占屏幕短边 ≥80%，四周留白，坐标不显示。
- 星位用小花点标注；可落子点按下时出现浅色光圈。
- 棋子：直径=格距×0.92，带轻微立体高光和投影。
- 故事模式棋子可换皮肤：黑子=小猫/砖块，白子=小狗/雨云，但需保留黑白主色。
- 气的可视化：棋子周围空交叉点显示星光黄小星星，数量即气数；仅剩1气时棋子做“紧张”表情并轻微抖动（打吃提示）。

## 3. 交互规范

### 3.1 落子方式
- **点按落子（默认）**：点交叉点 → 出现半透明预览子（300ms）→ 自动落下。
- **拖拽落子（可选）**：从棋罐拖出棋子，靠近交叉点吸附高亮，松手落子；拖出棋盘外松手则棋子弹回棋罐，无任何负面提示。
- 家长可在设置中开启“点两下确认落子”（适合易误触儿童）。
- 不可落点（已有子/禁入点）：棋子轻弹回+“咚”柔音+语音“这里放不下哦，换个地方吧”。

### 3.2 容错与撤销
- 屏幕底部常驻 **“倒回去”按钮**（时钟逆转图标，96pt），无限次撤销，不计次数、不扣星。
- 误触保护：连续快速点击（<200ms）只响应第一次。
- 连续3次未达成目标 → 自动出现“小提示”（目标位置闪烁光圈）；连续5次 → 语音演示正确一步。
- 中途退出自动保存进度。

### 3.3 无失败惩罚
- 不出现“失败”“错误”“Game Over”、扣分、倒计时、生命值。
- 错误操作 = 有趣的结果展示 + 鼓励（例：猫咪被围住时变成“躲猫猫”睡着，语音“哎呀，小猫被抓住啦，我们再救一次！”）。
- 星级只增不减；关卡完成即至少1颗星。

## 4. 少文字多语音

### 4.1 语音引导角色
- **“棋棋老师”**：一只戴围棋帽的小熊猫，温柔的年轻女声（语速约每分钟160字，比成人慢20%），始终在屏幕左下角，可点它重听指令。
- **配角**：小猫咪（救猫咪）、小松鼠建筑师（盖房子）、小企鹅们（找朋友），以拟声和短句出现。
- 规则：每句≤15字；一次只说一个指令；先说目标再说动作；用“我们”而非“你要”。

### 4.2 话术示例
| 场景 | 话术 |
|---|---|
| 开场 | “你好呀！我是棋棋老师，今天一起玩围棋吧！” |
| 介绍气 | “看，小猫身边的星星，是它能跑的路。” |
| 指令 | “帮小猫放一颗棋子，让它逃出去！” |
| 打吃提醒 | “小猫只剩一条路啦，快帮帮它！” |
| 正确 | “太棒啦！小猫逃走啦！”/“你真会想办法！” |
| 未达成 | “差一点点！我们再试一次。” |
| 提示 | “看看闪闪的地方，放这里试试？” |
| 做眼 | “房子要有两个窗户，才不会被吹倒哦。” |
| 连接 | “让小企鹅手拉手，就不怕啦！” |
| 完成 | “今天的任务完成啦！贴纸送给你！” |
| 休息 | “眼睛累了吧？我们明天再玩！” |
- 避免：“错了”“不对”“你不行”“快点”。

## 5. 动画与音效反馈清单
| 事件 | 视觉动画 | 音效 | 语音 | 时长 |
|---|---|---|---|---|
| 落子 | 棋子落下轻弹+涟漪 | 木质“哒” | — | 200ms |
| 正确一步 | 绿色光圈扩散+小星星飞出 | 清脆“叮~” | 随机表扬短句 | 600ms |
| 未达成/不可落 | 棋子轻摇回弹、粉色柔光 | 柔和“咚” | “再试试” | 400ms |
| 打吃（剩1气） | 棋子紧张表情+抖动 | 轻快“嘀嘀” | “只剩一条路啦” | 循环至解除 |
| 提子 | 被提棋子变泡泡飞走/变成小鸟飞走，计数+1飞入篮子 | “啵啵”泡泡声 | “吃掉啦！” | 800ms |
| 连接成功 | 棋子间出现“手拉手”连线 | 欢快和弦 | “手拉手啦！” | 600ms |
| 做成眼 | 窗户亮灯 | “叮咚”门铃 | “有窗户啦！” | 600ms |
| 关卡完成 | 彩带+角色跳舞+星星落入 | 短胜利乐句（≤3秒） | “太棒啦！” | 2–3s |
| 获得贴纸 | 贴纸从天而降，可拖到贴纸本 | “唰”+掌声 | “送你一张贴纸！” | 2s |
| 每日完成 | 太阳笑脸、晚安动画 | 摇篮曲片段 | 休息提醒 | 3s |
- 音量默认60%，背景音乐≤音效音量50%，可在家长区关闭。
- 禁止高频闪烁（>3次/秒）。

## 6. 贴纸奖励体系
- **获取**：完成关卡得1张普通贴纸；完成当日任务得1张“彩虹贴纸”；每个概念单元结业得“徽章贴纸”（猫咪救援员、小小建筑师、交友小达人、围棋小棋手）。
- **贴纸本**：主页右下角“书包”入口，每单元一页场景（猫咪乐园、房子小镇、企鹅冰岛），孩子可自由拖放贴纸布置场景。
- **连续性**：连续学习不设“断签惩罚”，中断后回来给“欢迎回来贴纸”。
- **节制**：每日贴纸上限约8张，避免过度奖励；奖励重在“收集+布置”的创造感而非数量比较；无排行榜、无内购换贴纸。
- **一个月成就**：集满4个徽章→ 解锁“毕业证书”（可由家长打印/分享）。

## 7. 游戏界面线框说明

### 7.1 救猫咪（气 / 逃跑）
- **目标概念**：气、打吃、长气逃跑、提子。
- **布局**：中央5路棋盘；黑子为小猫，白子为“小狗”围堵者；小猫周围的气显示为星星；左下棋棋老师；底部倒回去按钮；右上进度星。
```
┌──────────────────────────────────┐
│[⌂长按]        救猫咪      ★★☆   │
│                                  │
│      ┌───┬───┬───┬───┐           │
│      │   │ ✦ │   │   │           │
│      ├───●───🐱──○───┤ ✦=气(星星)│
│      │   │ ○ │   │   │ 🐱=小猫   │
│      ├───┼───┼───┼───┤ ○=小狗    │
│      │   │   │   │   │           │
│      └───┴───┴───┴───┘           │
│ 🐼棋棋老师                        │
│ “帮小猫逃出去！”   [↺倒回去]     │
└──────────────────────────────────┘
```
- **操作流程**：语音讲故事 → 星星闪烁展示气 → 孩子在气上落黑子延长 → 白方（AI）追堵一步 → 小猫气数≥3（或到达棋盘边“安全屋”）即成功。
- **反馈**：每延长一气星星增多并“叮”；剩1气猫咪紧张抖动；被提时猫咪变成“躲猫猫”睡着并提示再来；成功时猫咪跳舞。
- **难度递进**：
  1. 数星星：只点出小猫有几口气（点星星，不落子）。
  2. 一步逃跑：小猫1气，点唯一的星星逃出。
  3. 选择最佳逃跑方向（2个选项，一边是死路）。
  4. 反转角色“抓小狗”：给白子打吃并提子。
  5. 7路棋盘，多回合逃跑+反提。

### 7.2 盖房子（做眼 / 活棋）
- **目标概念**：眼、真眼与假眼（简化）、两只眼才能活。
- **布局**：7路棋盘一角显示“地基”轮廓；黑子为砖块，围出的空点是“窗户”；右侧显示需要的窗户数（2个窗户图标）；风婆婆（白子）会来“吹”。
```
┌──────────────────────────────────┐
│[⌂长按]       盖房子     窗户:🪟🪟 │
│                                  │
│   ┌──┬──┬──┬──┬──┬──┐            │
│   ■──■──■──■──┼──┼──┤  ■=砖(黑) │
│   ■──🪟─■──🪟─■──┼──┤  🪟=眼     │
│   ■──■──■──■──■──┼──┤            │
│   ├──┼──┼──┼──┼──○──┤  ○=风婆婆 │
│   └──┴──┴──┴──┴──┴──┘            │
│ 🐿️小松鼠：“再放一块砖！”         │
│ 🐼                   [↺倒回去]   │
└──────────────────────────────────┘
```
- **操作流程**：小松鼠展示地基 → 孩子落子补齐围墙 → 围出空点亮成窗户 → 风婆婆向窗户落子测试 → 只有1个窗户的房子被吹倒（被提），2个窗户的房子稳稳不倒。
- **反馈**：窗户亮灯“叮咚”；房子完成时屋顶落下、烟囱冒烟；被吹倒时砖块卡通散开再自动复原。
- **难度递进**：
  1. 补1块砖完成一个窗户。
  2. 对比实验：1个窗户 vs 2个窗户，看风婆婆吹。
  3. 孩子自己选位置做出第2个窗户。
  4. 识别“假窗户”（缺角的眼，可被风吹进）。
  5. 风婆婆对抗：轮流落子，抢先做出两眼。

### 7.3 找朋友（连接）
- **目标概念**：连接与切断，连起来的棋子共享气、更安全。
- **布局**：7路棋盘上分散的黑子为小企鹅，白子为“冰块”试图隔开；连接成功的企鹅之间出现手拉手连线；顶部显示需要团聚的企鹅数。
```
┌──────────────────────────────────┐
│[⌂长按]       找朋友     🐧×3团聚  │
│                                  │
│   ┌──┬──┬──┬──┬──┬──┐            │
│   │  │🐧──🐧 │  │  │  🐧=企鹅(黑)│
│   ├──┼──┼──┼──○──┼──┤  ○=冰块(白)│
│   │  │  │◌ │  │  │  │  ◌=提示点  │
│   ├──┼──┼──🐧─┼──┼──┤            │
│   └──┴──┴──┴──┴──┴──┘            │
│ 🐧“我也想手拉手！”               │
│ 🐼                   [↺倒回去]   │
└──────────────────────────────────┘
```
- **操作流程**：企鹅喊“我好孤单” → 孩子在两只企鹅之间落子 → 相邻同色子出现手拉手、合并共享星星（气） → 所有企鹅连成一队即过关。
- **反馈**：连接时和弦音+拉手动画，气星星合并数量增加；被冰块切断时企鹅挥手“我在这儿”提示；全部团聚时企鹅跳圈圈舞。
- **难度递进**：
  1. 直接相邻连接（一步）。
  2. 斜对角需补一子（理解斜线不算连接）。
  3. 冰块会抢点：先连哪一处更急。
  4. 双方对抗：连接自己同时切断对方。
  5. 9路综合：连接+逃跑+提子，过渡到完整对局。

### 7.4 一个月学习路线（参考）
| 周 | 棋盘 | 主题 |
|---|---|---|
| 第1周 | 5路 | 救猫咪：气、打吃、提子 |
| 第2周 | 7路 | 找朋友：连接与切断 |
| 第3周 | 7路 | 盖房子：做眼、活棋 |
| 第4周 | 9路 | 综合挑战 + 与AI小熊猫下完整一盘（吃子棋→完整规则） |

## 8. 家长区与使用时长保护

### 8.1 家长区入口
- 右上角“锁”图标长按1.5秒 → 家长验证（简单算术题如“7×8=?”或手势题，避免儿童误入）。
- 家长区界面为成人风格，可正常文字阅读。

### 8.2 家长区功能
- 学习报告：每日时长、完成关卡、掌握概念雷达图（气/提子/连接/做眼/对局）、需加强项。
- 设置：单日时长上限（默认15分钟，可选10/15/20/30）、可用时段（如19:00后禁用）、音量与背景音乐、落子确认方式、棋盘难度微调。
- 家长指导卡：每个概念一张“亲子共玩小贴士”，含实体棋盘延伸活动。
- 隐私：不收集儿童语音/照片，无广告、无社交、无内购弹窗；账号与付费仅在家长区。

### 8.3 使用时长保护
- 单次学习结束前2分钟：棋棋老师提醒“再玩一关就休息啦”。
- 到时：完成当前关卡后（不中断关卡）播放“晚安”动画，进入休息锁屏；需家长验证才能延长。
- 每15分钟强制护眼提示（远眺动画20秒）。
- 不使用诱导回访的推送；家长可开启每日固定时间提醒（推送给家长端）。
