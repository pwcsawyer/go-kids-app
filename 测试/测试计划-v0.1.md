# 测试计划 v0.1（草稿，待需求文档补齐后细化）

## 1. 适龄验证
- A1 五岁儿童无需大人帮助，能从启动走到第一节课（只靠语音和图标提示）
- A2 单节课时长不超过 10 分钟，按 P90 统计
- A3 拖拽或点击落子的误触率：按钮和交叉点的点击区域 ≥ 44pt
- A4 出错时给温和的反馈，不出现惩罚性提示；奖励贴纸能正常发放
- A5 不认字的孩子也能看懂全部流程（文字只是辅助）
- 方法：5–8 名五岁儿童做可用性观察，记录完成率、求助次数和用时

## 2. 规则引擎（小棋盘 5x5 / 7x7 / 9x9）
- R1 气的计算：单子、连通块、棋盘边和角上的棋子
- R2 提子：单提、多块同时被提、提子后气要重新计算
- R3 禁入点：落子后自己没气且提不了对方的子，判为非法
- R4 例外：落子后能提掉对方的子，即使看起来是禁入点也合法
- R5 打劫：不能立即回提，隔一手后可以
- R6 胜负判定（吃子棋）：谁先提够约定的子数谁就赢；同一手里提子跨过目标数也立即判胜；一方没有合法落子点时怎么算，待产品确认
- R7 每一类各建立“棋盘局面 + 期望结果”的固定用例集，用于自动化回归

## 3. Bug 流程
- 严重级别：P0 崩溃或规则判错，P1 流程卡住，P2 体验问题
- 每个版本先跑规则回归，再做适龄抽测
